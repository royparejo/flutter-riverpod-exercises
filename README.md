# Flutter Riverpod 3 Exercises

This repository contains my implementation of the exercises and concepts taught in the Riverpod tutorial series by **DolphWare**. The purpose of this project is to reinforce Riverpod fundamentals through hands-on practice and serve as a reference for other Flutter developers learning state management.

## Acknowledgements

## UI-Only Branch

A dedicated branch named `ui-only` is available for developers who want to practice Riverpod on their own.

This branch contains:

* Completed Flutter UI
* No Riverpod implementation
* Ready-to-use screens and widgets

You can use it to implement your own providers, state management solutions, and compare your approach with the completed implementation in the main branch.
